# 3d-printing

3Dプリント事業の紹介・お問い合わせページ（`index.html` 1ファイルのみ）。

## 使い方
- `index.html` をブラウザで開くだけで表示できます。
- `index.html` 下部の `CONTACT_EMAIL` を自分のメールアドレスに変更してください。
  お問い合わせフォームの送信ボタンを押すと、入力内容が入った状態でメールソフトが開きます。
- 屋号・料金・対応素材などの文言は `index.html` 内を直接書き換えてください。

## 公開方法（例）
GitHub Pages: リポジトリの Settings → Pages → Branch を選んで保存すると公開されます。
