# PIPPI STUDIO

3Dプリント造形サービス「PIPPI STUDIO」の紹介・お問い合わせページ（`index.html` 1ファイルのみ、アメコミ風デザイン）。

## 使い方
- `index.html` をブラウザで開くだけで表示できます。
- お問い合わせフォームの送信ボタンを押すと、入力内容が入った状態でメールソフトが開き、`hyusuke0509@gmail.com` 宛てに送られます（送信先は `index.html` 下部の `CONTACT_EMAIL`）。
- 文言・色は `index.html` 内を直接書き換えてください（色は先頭の `:root` で一括変更できます）。

## 公開方法（例）
GitHub Pages: リポジトリの Settings → Pages → Branch を選んで保存すると公開されます。
